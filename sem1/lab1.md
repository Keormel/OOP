## Абстрактные типы данных

## Объяснение программы

В программе создан класс `Student`, который хранит имя студента и его оценку:

```cpp
private:
    string name;
    int grade;
```

Поля находятся в `private`, поэтому к ним нельзя обращаться напрямую из `main()`. Для работы с ними используются методы класса.

Основные методы:

* `Student()` — задаёт начальные значения;
* `setData()` — устанавливает имя и оценку;
* `getName()` — возвращает имя;
* `getGrade()` — возвращает оценку;
* `print()` — выводит данные;
* `clear()` — возвращает начальные значения.

Конструктор автоматически вызывается при создании объекта:

```cpp
Student student;
```

Для проверки правильности работы используется `assert()`:

```cpp
assert(student.getGrade() == 5);
```

Если условие выполняется, программа продолжает работу. Если нет — программа сообщает об ошибке.

Использование `private` для данных и `public` для методов показывает принцип **инкапсуляции**.

# Контрольные вопросы

### 1. Какие типы данных называют абстрактными и почему?

Абстрактный тип данных — это тип, который определяется данными и операциями над ними. При этом его внутреннее устройство может быть скрыто от пользователя.

### 2. Какие примеры абстрактных типов данных можно привести?

Стек, очередь, список, множество, словарь, матрица, комплексное число.

### 3. Какая разница между `struct` и `class`?

Главное отличие — уровень доступа по умолчанию.

У `struct` элементы по умолчанию `public`, а у `class` — `private`.

```cpp
struct A
{
    int x; // public
};

class B
{
    int x; // private
};
```

### 4. Что такое инкапсуляция?

Инкапсуляция — это объединение данных и методов внутри класса и ограничение доступа к внутренним данным.

# Опциональное задание

### 1. Какова роль `public` и `private`?

`public` делает элементы доступными из внешнего кода.

`private` скрывает элементы класса от внешнего кода.

В нашей программе поля `name` и `grade` являются `private`, а методы класса — `public`.

### 2. Какая разница между методами класса и свободными функциями?

Свободная функция существует отдельно от класса.

Метод является частью класса и вызывается для конкретного объекта:

```cpp
student.print();
```

Методы имеют доступ к закрытым данным своего класса.

### 3. Каковы особенности использования статических методов класса?

Статический метод принадлежит классу, а не конкретному объекту.

Его можно вызвать без создания объекта:

```cpp
ClassName::method();
```

Статический метод не может напрямую обращаться к обычным нестатическим полям объекта.

### 4. Как отличается инициализация объектов пользовательского типа от объектов встроенных типов?

Объекты класса могут иметь конструктор, который автоматически выполняется при создании объекта.

```cpp
Student student;
```

Встроенные типы, например `int`, необходимо инициализировать явно, если требуется определённое начальное значение:

```cpp
int x = 0;
```
