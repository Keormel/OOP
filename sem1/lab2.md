# Лабораторная работа 2 — Конструкторы, деструктор

## Что реализовано

Класс `MyArray` — простой динамический массив целых чисел. Хранит указатель
на массив в куче (`int* data`) и его размер (`int count`). Память — это
ресурс, за который отвечает сам класс: выделяет её в конструкторах,
освобождает в деструкторе, а также в `clear()`, `resize()` и `assign()`,
когда старый массив нужно заменить новым.

Код написан максимально просто и наглядно — обычные циклы `for`, без
"продвинутых" вещей вроде `explicit`, `noexcept` или `static_cast`, чтобы
было легко проследить, что происходит на каждом шаге.

### Конструкторы (все создают объект из данных "другого типа")

| Конструктор | Источник данных |
|---|---|
| `MyArray()` | нет источника — значения по умолчанию (пустой массив) |
| `MyArray(int n)` | число `n` → массив из `n` нулей |
| `MyArray(initializer_list<int>)` | список `{1,2,3}` → массив тех же значений |
| `MyArray(int[], int)` | обычный массив + его длина → копия массива |
| `MyArray(const MyArray&)` | другой объект того же класса → **своя копия** данных |
| `MyArray(MyArray&&)` | временный объект → **забираем** у него указатель |

### Деструктор
`~MyArray()` вызывает `delete[] data` — освобождает память. Компилятор
вызывает его сам, когда объект выходит из области видимости.

### Методы
- `clear()` — освобождает память, обнуляет поля.
- `at(int)` — доступ по индексу; отрицательный индекс отсчитывается с конца,
  выход за границы "прижимается" к первому/последнему элементу.
- `resize(int)` — обрезает либо дополняет нулями.
- `assign(int, int)` — полностью заменяет содержимое.
- `empty()`, `size()` — простые проверки размера.
- `swap(MyArray&)` — меняет местами указатели `data` и значения `count`
  через временные переменные, без копирования самих элементов.
- `static is_equal(a, b)` — сравнивает размеры и элементы по очереди.

`main()` по очереди показывает каждый конструктор и метод, выводя состояние
массива до и после операции.

Файл собирается любым современным компилятором:
```
g++ -std=c++17 -Wall -Wextra -o lab2 main.cpp
./lab2
```

## Контрольные вопросы (первый блок)

**1. Что такое конструктор? С какой целью их объявляют в классе?**
Конструктор — специальный метод класса с именем, совпадающим с именем класса,
без возвращаемого типа, который автоматически вызывается в момент создания
объекта. Его цель — инициализировать внутренние поля объекта в корректное
(валидное) состояние, в том числе выделить ресурсы (память и т.п.), которые
объект будет использовать.

**2. Как конструкторы используются в программе?**
Явно программист их не вызывает — конструктор вызывается компилятором
неявно при: объявлении переменной (`IntCollection b(5);`), создании через
`new`, копировании/переносе объекта, передаче/возврате объекта по значению.
Если в классе объявлено несколько конструкторов (перегрузка), компилятор
выбирает нужный на основе типов и количества переданных аргументов.

**3. Что такое деструктор? С какой целью его объявляют в классе?**
Деструктор — специальный метод `~ИмяКласса()` без параметров и без
возвращаемого значения, вызывается автоматически при уничтожении объекта.
Его цель — корректно освободить ресурсы, полученные объектом за время жизни
(динамическую память, файловые дескрипторы, сетевые соединения и т.д.),
чтобы избежать утечек.

**4. Как деструктор используется в программе?**
Так же, как и конструктор — неявно, компилятором: при выходе объекта из
области видимости (для локальных объектов), при `delete` для объектов,
созданных через `new`, либо при уничтожении содержащего объекта/контейнера.
Вручную деструктор почти никогда не вызывают — это гарантирует, что ресурсы
освободятся всегда, даже если функция завершится через исключение (принцип
RAII).

## Контрольные вопросы (второй блок)

### 1. Какие 3 конструктора являются особенными и генерируются компилятором?

Основные специальные конструкторы:

* конструктор по умолчанию;
* конструктор копирования;
* конструктор перемещения.

Они могут автоматически создаваться компилятором, если класс не объявляет собственные версии.

### 2. В чём разница между копированием и перемещением?

**Копирование** создаёт независимую копию данных, поэтому может требовать выделения памяти.

**Перемещение** передаёт ресурсы от одного объекта другому без копирования данных, поэтому обычно работает быстрее.

Конструктор перемещения вызывается для временных объектов (`rvalue`) или при использовании `std::move()`.

### 3. В чём разница между l-value, r-value и константными ссылками?

`lvalue` — именованный объект, например переменная `x`.

`rvalue` — временное значение или объект.

* `T&` — ссылка на `lvalue`;
* `T&&` — ссылка на `rvalue`, используется для перемещения;
* `const T&` — может ссылаться и на `lvalue`, и на `rvalue`, но не позволяет изменять объект.

### 4. В чём особенность сравнения двух объектов?

Сравниваются только данные, которые определяют значение объекта: элементы и их количество.

Служебные данные, например адрес указателя `data_`, не сравниваются, потому что они не влияют на логическое равенство объектов.

### 5. В чём особенность `swap` для пользовательского класса?

Для эффективного `swap` достаточно обменять служебные поля, например указатель `data_` и размер `size_`.

Такой обмен выполняется за **O(1)** и не требует копирования всех элементов. Обычно такой метод объявляют с `noexcept`.
